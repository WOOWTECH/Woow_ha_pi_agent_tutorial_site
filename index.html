from zero to running
Home Assistant 新居入住指南

從零到能用

把剛裝好的 Home Assistant 從空白狀態，一路設定到可以在牆上點兩下開燈、在手機上收到通知，再往下走到通訊協定、能源監控、語音助理與案場級的網路架構。22 章＋ 3 附錄，每章 10 分鐘。

起步認識

01

這個 AI 工作站是什麼

Pi Agent 是家裡多一個 AI 工作站，附上 5 分鐘 HA 導覽，讓沒看過入住指南的人也接得住。

 02

裝好 Pi Agent

加倉庫、按安裝、首次開機為什麼要等 3-8 分鐘，一次講完。

 03

從側邊欄打開它

為什麼側邊欄自己就出現一顆按鈕、admin 才看得到、手機也能連。

 04

工作區長什麼樣

打字區、模型下拉、Session 歷史、右上工具列，一次認完不再迷路。

先跟它聊起來

05

加第一個 AI 大腦：申請 GLM 金鑰

從註冊帳號到拿到 API key，一步步截圖照著點就好。

 06

把金鑰貼進 Models 面板

打開 Models 面板、按 Add Provider、填 baseUrl 與 key、按 Test 綠燈。

 07

開第一個對話

問一個真實的家庭問題，看 AI 回什麼、學會怎麼繼續追問。

 08

Session 是什麼？跟聊天室有什麼不一樣

為什麼要分很多個 Session、fork 是什麼、匯出跟清理怎麼做。

 09

對話裡的思考塊、工具卡片、diff 是什麼

AI 回答旁邊那些可以展開的方塊，各自是幹嘛的、什麼時候該讀。

多個 AI 一起用

10

為什麼要接不只一家 AI

便宜、快、想得深各挑一個，日常用起來會發現差很多。

 11

六種主流 provider 各適合什麼場合

GLM、OpenAI、Anthropic、DeepSeek、Groq、OpenRouter 一頁看懂。

 12

有想的、沒想的：Reasoning 模型是什麼

為什麼有些 AI 會先在心裡想一輪、什麼時候值得多花那個錢。

 13

一句話切換 AI：模型下拉的正確用法

同一個問題丟給不同 AI 對比，是最快看懂差別的辦法。

Skills 讓 AI 學新本事

14

Skill 是什麼？跟手機 App 有什麼不一樣

把 Skill 想成教 AI 一項專門手藝，用類比一次講清楚。

 15

從 GitHub 裝別人做好的 Skill

Skills 面板實操：搜尋、貼 GitHub URL、按裝、看它出現在系統提示裡。

 16

自己動手做第一個 Skill

SKILL.md 骨架 + 家庭場景範例：教 AI 幫你算冰箱食材要不要補。

讓 AI 幫你做影片

17

影片管線：從腳本到 YouTube 可上傳

AI 幫你寫腳本、配音、抓畫面、剪接、燒字幕，一路做到能傳的 MP4。

 18

為什麼首次要下載 720MB、之後就秒開

video-tools-init 在裝什麼、放在哪、什麼時候會重新裝一次。

 19

成品自動傳 Google Drive：rclone 一次設好

rclone 設定跑一次 OAuth，之後每支影片自動上傳到指定資料夾。

家常維護

20

對話與金鑰的備份：跟 HA snapshot 一起走

什麼會被備到 HA snapshot、什麼不會、還原後要補做什麼。

 21

升級 Pi Agent：v0.13.0 API key 搬家踩雷筆記

從舊版升上來會發現 API key 欄位不見了，是搬家不是遺失。

 22

常見卡關手冊

401／402／404、Ingress 掉、影片管線失敗、Skill 裝不起來，一頁找解法。
