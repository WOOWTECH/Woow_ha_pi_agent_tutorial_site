七家 provider 金鑰申請速查

Pi Agent 是自帶金鑰（BYOK, Bring Your Own Key）的介面，本身不賣 AI。這附錄把七家常用 provider——GLM、OpenAI、Anthropic、DeepSeek、Groq、MiniMax、OpenRouter——的註冊入口、金鑰位置、Pi Agent 填法、費率頁、常見卡關一次列齊。之後每次要接一家新的 AI 大腦，翻這頁對照抄就好，不用再一家一家去找入口網址。這是速查手冊，每個 section 之間可以獨立看，不必從頭讀到尾。

為什麼要這一頁

Pi Agent 支援的 provider 越來越多，但每次要新加一家，你都會撞到同樣三個問題：

  • 入口網址在哪？ Google 搜「GLM API」跳出來十幾個看起來很像的頁面，哪個才是真的？智譜開放平台跟智譜清言（AI 對話網站）長得很像、網址完全不同。
  • API keys 選單藏哪裡？ 每家後台的名字不一樣——OpenAI 叫 API keys、Anthropic 叫 API Keys（在 Settings 底下）、GLM 叫「API 金鑰管理」、DeepSeek 叫 API Keys 但入口在左側欄。第一次找常常要點五分鐘。
  • Pi Agent 該怎麼填？ 拿到金鑰只是一半，另一半是要在 Pi Agent 的 Models 面板選對 api mode、貼對 baseUrl、指對 model 名字。任何一格填錯都會 Test 紅叉。

這附錄把七家答案一次寫齊。已經看過第 5 章申請 GLM、第 6 章把金鑰貼進 Pi Agent 的話，這裡就是「同樣的流程套到另外六家」的對照表。看過第 10 章為什麼要多接幾家、第 11 章六家對照的話，這裡多出來的是 MiniMax 那家，還有每家的實務坑。

觀念：Pi Agent 是把「你和 provider 的鑰匙」交給它保管的 BYOK 介面，鑰匙留在你家 HA 硬碟（/data/pi-agent/models.json）。所以你申請多少家、用哪一家、花多少錢，都是你直接跟 provider 那邊算帳，Pi Agent 不經手。

申請 provider 金鑰的通用四步驟

七家長得都不一樣，但流程幾乎是同一套。任何一家新的 provider 上手都是這四步：

  1. 註冊帳號

    多數家要 email + 手機驗證。少數（Anthropic、OpenAI）可以用 Google 或 Apple 一鍵登入省掉密碼。中國家（GLM、DeepSeek、MiniMax）通常要中國或台灣手機收簡訊。Groq、OpenRouter 支援 GitHub 一鍵登入。

  2. 綁付款方式或吃免費額度

    大部分家新戶都會送一點免費額度：GLM 送幾千萬 tokens、DeepSeek 送幾塊人民幣、Groq 純免費（有 rate limit）、OpenRouter 每天 50 free requests。想長期用就要綁信用卡或儲值。台灣信用卡在 OpenAI／Anthropic／OpenRouter 通常可以，中國家（GLM／DeepSeek／MiniMax）要用支付寶或微信支付。

  3. 到「API keys」／「開發者中心」建 key

    每家後台入口位置不同，這附錄每一 section 都寫了確切位置。共同原則：金鑰只在「產生的那一次」看得到完整值，離開頁面之後就只剩前後幾碼給你認。所以按 Copy 之後一定要先貼到密碼管理器（Bitwarden、1Password、Keychain 都行）存一份。

  4. 貼進 Pi Agent Models 面板 + Test

    打開 Pi Agent 右上 Models → Add Provider → 填 Name／API mode／baseUrl／apiKey → 加一個 model entry → 按 Test。3-5 秒內綠勾＝連得上，紅叉＝有一格填錯。第 6 章把每一步都拆給你看過，這裡就不重複，直接看每家「Pi Agent 填法」那行照抄。

提示：七家不用一次全申請。日常聊天一家夠用就一家（GLM 或 DeepSeek 都便宜），寫程式加 Anthropic，急件加 Groq，其他等真的用到再說。附錄 B 的意義是「你哪天想加，翻這頁就查到」，不是「開卷第一天就每家都辦」。

GLM（智譜清言）

中國智譜 AI 的旗艦系列，性價比高、支援思考塊（reasoning）、200k context。新戶免費額度大方，是台灣使用者「入門第一支金鑰」的常見選擇。第 5 章整章拆解過完整流程，這裡只列速查。

項目內容
註冊入口https://open.bigmodel.cn/（智譜開放平台，不是智譜清言的 chat 網站）。手機號碼收簡訊驗證。
金鑰位置登入後右上頭像 → 個人中心 → API 金鑰管理 → 新增。金鑰只顯示一次要立刻複製。
費率頁https://open.bigmodel.cn/pricing
Pi Agent api modeopenai-completions（相容 OpenAI 格式）
Pi Agent baseUrlhttps://open.bigmodel.cn/api/paas/v4（結尾不要多斜線）
推薦 modelglm-4.6（旗艦、會思考、200k context）、glm-4-air（輕量便宜）、glm-4-flashx（極速閒聊）
thinkingFormatzai（Pi Agent 內建的智譜思考塊解析器）

典型 Add Provider 表單填法：

Name:           GLM
API mode:       openai-completions
Base URL:       https://open.bigmodel.cn/api/paas/v4
API key:        (貼你剛複製的那串)
Model name:     glm-4.6
thinkingFormat: zai
注意：GLM 的實名認證需要中國身分證。台灣手機可以完成簡訊驗證、拿到金鑰、用免費額度，但要儲值就要另想辦法——最常見是找有支付寶的朋友代刷，或改用 OpenRouter 走 zhipu/glm-4.6 用台灣信用卡結。

OpenAI

ChatGPT 背後的公司，模型指標一直是業界標竿。gpt-4o 全能、gpt-4o-mini 便宜又快、o1／o3 系列會深度思考但貴。台灣可以用信用卡直接付。

項目內容
註冊入口https://platform.openai.com/signup（platform 是開發者後台，跟 chat.openai.com 是不同帳號體系但可共用登入）
金鑰位置登入後右上頭像 → View API keys（或左側 Dashboard → API keys）→ Create new secret key。
費率頁https://openai.com/pricing
Pi Agent api modeopenai-completions
Pi Agent baseUrlhttps://api.openai.com/v1
推薦 modelgpt-4o（旗艦全能）、gpt-4o-mini（便宜快、日常足夠）、o1-mini（會思考的便宜版）
thinkingFormat留空（gpt-4o 系列不回思考塊；o1 系列有自己的內部推理但 API 不回傳過程）
注意：OpenAI 對某些國家／地區發卡的信用卡會直接拒絕（風控嚴）。台灣核發的 Visa／Master 通常可以，但偶爾要試兩三張。如果家裡有訂 iCloud＋家庭方案／Nabu Casa 的信用卡（都是 Apple ID 綁的），那張卡刷 OpenAI 通常也過得了。
提示：OpenAI 新戶不像以前那樣送免費 $5 額度了，現在要先儲值最少 $5 才能開始用。gpt-4o-mini 一百萬 tokens 才 $0.15，$5 可以打字打到手斷。

Anthropic

Claude 系列的公司，寫程式跟長文推理特別強、有原生的 thinking blocks（會思考的模型會把思考過程結構化回傳）和 prompt caching（自動快取常見前綴省錢）。這附錄裡唯一一家 api mode 不選 openai-completions 的。

項目內容
註冊入口https://console.anthropic.com/。Google 一鍵登入或 email。
金鑰位置左下齒輪 → Settings → API Keys → Create Key。金鑰以 sk-ant- 開頭。
費率頁https://www.anthropic.com/pricing
Pi Agent api modeanthropic（不是 openai-completions！）
Pi Agent baseUrl官方預設就好，可留空或填 https://api.anthropic.com
推薦 modelclaude-sonnet-4-6（日常均衡）、claude-opus-4-7（最強、貴）、claude-haiku-4-5（便宜快）
thinkingFormat用 anthropic api mode 時 Pi Agent 會自動處理，無需另填

典型 Add Provider 表單填法：

Name:           Anthropic
API mode:       anthropic          ← 注意！不是 openai-completions
Base URL:       (留空，用官方預設)
API key:        sk-ant-...
Model name:     claude-sonnet-4-6
注意：如果 api mode 錯選 openai-completions 送到 Anthropic 的端點，會直接 401（協議完全不同）。這是最常見的踩雷。台灣信用卡通常可以正常刷，且不需要中國支付手段。

DeepSeek

中國幻方旗下的實驗室，deepseek-chat 是全球目前性價比之王之一，deepseek-reasoner（R1 系列）是開源推理模型。相容 OpenAI 格式、API 定價便宜到誇張。

項目內容
註冊入口https://platform.deepseek.com/。手機或 email 註冊。
金鑰位置左側欄 API Keys → Create API Key。金鑰以 sk- 開頭。
費率頁https://api-docs.deepseek.com/quick_start/pricing
Pi Agent api modeopenai-completions
Pi Agent baseUrlhttps://api.deepseek.com/v1
推薦 modeldeepseek-chat（V3，日常聊天）、deepseek-reasoner（R1，會思考）
thinkingFormatdeepseek-chat 留空；deepseek-reasoner 填 deepseek
注意：DeepSeek peak 時段（東亞白天）常撞 rate limit，回傳會很慢或直接 429。要穩定用就得儲值升等或分流到別家。deepseek-reasoner（R1）才有思考塊，deepseek-chat 沒有——想看 AI 推理過程要選對模型。

Groq

不是 Elon 的 Grok，是另一家做「LPU 推理硬體」的美國公司，強項是速度——同樣 Llama-3.3 70B 在 Groq 上一秒 500+ tokens，比其他家快 5-10 倍。免費 tier 就能用，適合當急件備援。

項目內容
註冊入口https://console.groq.com/。GitHub / Google 一鍵登入。
金鑰位置左側 API Keys → Create API Key。金鑰以 gsk_ 開頭。
費率頁https://groq.com/pricing/（免費 tier 有 rate limit，付費 tier 便宜）
Pi Agent api modeopenai-completions
Pi Agent baseUrlhttps://api.groq.com/openai/v1
推薦 modelllama-3.3-70b-versatile（開源模型旗艦）、moonshotai/kimi-k2-instruct（Moonshot 的 Kimi K2）
thinkingFormat多數留空。跑 reasoning 模型時視模型而定。
注意：Groq 的模型陣容變動很快，官方會不定時下線舊模型（例如 mixtral-8x7b 就被下架過）。如果你的 Pi Agent 突然對某個模型連不上，先去 console.groq.com/docs/models 看該 model 名稱是否還在名單裡。

MiniMax

中國 MiniMax 的模型系列，MiniMax-M2 是 2025 年的旗艦——1M context、支援 reasoning、相容 OpenAI 格式。特色是超長 context 適合塞整本 PDF 進去問。國際版跟中國版分兩個 endpoint。

項目內容
註冊入口國際版 https://api.minimax.io/（推薦）；中國版 https://api.minimax.chat/。兩邊帳號不通，選一邊就固定用那邊。
金鑰位置登入後 帳戶設定 → API Key → 新建。
費率頁官網 pricing 頁（不同 endpoint 有各自的價目表，以你註冊那邊為準）
Pi Agent api modeopenai-completions
Pi Agent baseUrl國際版：https://api.minimax.io/v1；中國版：https://api.minimaxi.com/v1（多一個 i）
推薦 modelMiniMax-M2（2025 旗艦、1M context、有思考塊）、abab7-chat-preview（前代通用）
thinkingFormatMiniMax-M2 填 deepseek（M2 用 <think> tag，跟 DeepSeek 格式相容）；abab7 留空
注意：國際／中國兩個 endpoint 千萬別搞混——同一支金鑰只能在註冊那邊用，跨邊會 401。1M context 是 MiniMax-M2 才有，選 abab7 一樣只有 32k 左右。

OpenRouter

不是 AI 廠商，是「AI 中盤商」——用一支金鑰、一個 baseUrl，就能通吃上百個模型（OpenAI、Anthropic、Google、Meta、Mistral、xAI、Perplexity、DeepSeek、GLM、Cohere 全都在）。台灣信用卡通常可以直接刷，也支援加密貨幣充值。

項目內容
註冊入口https://openrouter.ai/。Google 或 GitHub 登入。
金鑰位置登入後右上頭像 → Keys → Create Key。金鑰以 sk-or-v1- 開頭。
費率頁每個模型有自己的原廠 rate，OpenRouter 額外收約 5.5% 手續費（或最低 $0.0001／request，看哪個大）。等於你付「原價 × 1.055」，方便換取「一把 key 通吃」。
Pi Agent api modeopenai-completions（OpenRouter 統一用 OpenAI 相容格式，連 Anthropic 模型走這裡也是 openai-completions）
Pi Agent baseUrlhttps://openrouter.ai/api/v1
推薦 model用 provider/model 格式：anthropic/claude-sonnet-4.6、openai/gpt-4o、deepseek/deepseek-chat、google/gemini-2.5-pro
thinkingFormat看你選哪個模型；思考塊格式會被 OpenRouter 標準化，通常留空即可
注意：Anthropic 模型走 OpenRouter 這條，會失去 native thinking blocks 跟 cache_control——因為 OpenRouter 把所有家都塞進 openai-completions 這個共同格式，走原廠 anthropic api mode 才有的功能會被拉平。要用 Claude 的思考塊或省 cache 錢，還是直接跟 Anthropic 辦一支金鑰比較划算。
提示：OpenRouter 適合當「一次試多家 AI 比較」的沙盒。你不確定要辦哪家、想同一個問題丟 6 家對比看誰答得好，OpenRouter 一把 key 就能做完，不用一次辦 6 個帳號。第 13 章示範的模型下拉切換就是這個工作流。

申請常見卡關

七家不同的坑歸納出來就這幾類：

  1. 申請完貼進 Pi Agent、按 Test 紅叉

    先按以下順序排查：（1）baseUrl 結尾有沒有多一個 /——例如打成 .../v4/ 而不是 .../v4，多數 provider 會直接 404；（2）金鑰有沒有頭尾空白——網頁選字段常會多選到一格空白，貼進 Pi Agent 前先貼到記事本檢查；（3）api mode 選對沒——Anthropic 用 anthropic，其他六家用 openai-completions，選錯直接 401 或 400；（4）model 名字打對沒——例如 glm-4.6 少打 .6 變 glm-4 就 404 model not found。第 6 章 troubleshoot 有完整錯誤碼對照。

  2. 台灣信用卡刷不了

    依 provider 分開處理：（1）OpenAI／Anthropic——換一張卡，或改用綁在 Apple ID 上的 iCloud 家庭方案卡（那張卡通常過得了）；（2）GLM／DeepSeek／MiniMax（中國家）——找有支付寶／微信支付的朋友代刷儲值，或改走 OpenRouter 用它們的模型（例如 openrouter/zhipu/glm-4.6、openrouter/deepseek/deepseek-chat）；（3）不想麻煩——用 Wise 或 Revolut 開一張虛擬卡，多數海外 provider 都認；（4）直接用 OpenRouter——它一把 key 通吃多家，只多付 5.5% 手續費省下辦 5 個帳號的力氣。

  3. 手機驗證卡住（收不到簡訊）

    某些家支援 email 驗證代替手機——OpenAI、Anthropic、Groq、OpenRouter 都可以純 email。中國家（GLM、DeepSeek、MiniMax）比較堅持要手機。台灣門號多數收得到中國家的簡訊，收不到的話：（1）看垃圾簡訊夾；（2）改用中華電信網頁版看有沒有被擋（少數電信商會把大陸來的簡訊當廣告擋）；（3）等 5 分鐘按重發；（4）換另一支台灣號碼試（同一支號常有連續發送冷卻）。

  4. 中國家的入口（GLM / DeepSeek / MiniMax）在你家網路打不開

    台灣少數 ISP（例如某些 4G 熱點的分享網路）會擋 *.cn。試三招：（1）手機開網頁看能不能開——手機走 4G 的路徑跟家裡 WiFi 走的 ISP 常常不同，能開就代表是家裡網路的 DNS／防火牆擋住；（2）換 DNS——把家裡 router 或裝置的 DNS 從中華電信預設改成 8.8.8.8（Google）或 1.1.1.1（Cloudflare），多數擋大陸站的 DNS 過濾會失效；（3）還是不行就走 OpenRouter——OpenRouter 的入口是美國 IP，一定能開，然後用它代理連中國家的模型。

  5. 金鑰產生後沒複製到、關掉頁面就再也看不到

    七家都一樣：金鑰只在「產生的那一次」顯示完整值，之後回後台只看得到前後幾碼。沒複製到就沒救了，直接把那支停用、重新產生一支新的，這次一定要先貼到密碼管理器再繼續。這不是 bug 是安全設計——如果後台隨時可以複製整支 key，你的密碼一被盜整批 key 就外流。

  6. 某家 Test 綠燈，過幾天突然變紅叉

    三個可能：（1）免費額度用完——回該家後台看餘額，儲值就活；（2）模型被下架（Groq 特別常見）——去 provider docs 看該 model 是否還在名單，改成新推薦模型；（3）金鑰被判定異常——某些家（OpenAI 特別嚴）如果偵測到不尋常流量會自動停用金鑰，去後台看有沒有安全通知，需要就重發一支。

常見問題

七家一定要每家都申請嗎？
不用。日常聊天一家就夠，選 GLM（免費額度大方）或 DeepSeek（付費也超便宜）都行。等你真的用到「這家做不到那家能做」的場景再加：想寫程式加 Anthropic、想急件加 Groq、想比較不同 AI 加 OpenRouter、想塞長文加 MiniMax。第 10 章整章在講「什麼時候值得多接一家」，可以先看那章再決定要辦幾支。
同一支金鑰能不能給多台裝置共用？例如手機、平板、家裡 HA 都用同一支？
可以。金鑰本質就是一串字，貼到哪台裝置的 Pi Agent 都能用，用量會全部算在同一個帳戶名下。不建議：多人共用同一支 key（分不清誰花的錢、萬一其中一人手機掉了整支 key 要作廢）。建議：一台 HA、一個家庭成員各發一支獨立 key，多數 provider 後台允許同一帳號建 5-10 支 key。分開 key 的另一個好處是第 6 章提的「Provider name 分家用／辦公用」，看帳單一目瞭然。
什麼 provider 最適合完全新手第一次辦？
兩個推薦：（1）GLM——註冊送幾千萬 tokens 免費額度，等於幾百塊台幣，光免費就能玩很久；且中文效果好、有思考塊看得到 AI 怎麼想。缺點是要付費就得搞支付寶。（2）Groq——完全免費 tier 就能用，速度超快很有成就感，適合當「打開 Pi Agent 第一次玩」的體驗。缺點是模型陣容比較窄（主要跑開源 Llama/Kimi/Mixtral）。等玩熟了再加 Anthropic 或 OpenAI 這種要付費、但品質更高的旗艦家。
有沒有辦法所有家一次搞定、不用一家一家申請？
有，就是 OpenRouter。它幫你聚合上百個模型，你辦一個 OpenRouter 帳號、拿一支 key，就能跑 openai/gpt-4o、anthropic/claude-sonnet-4.6、deepseek/deepseek-chat、zhipu/glm-4.6、meta/llama-3.3-70b… 幾乎全部。代價是每次呼叫多付約 5.5% 手續費（等於「原廠價 × 1.055」），換取免辦 6 個帳號、免處理 6 種支付方式的省心。缺點：Anthropic 走 OpenRouter 會失去 native thinking blocks 跟 cache_control 這兩個省錢功能，長期重度用 Claude 的人還是直接辦 Anthropic 帳號划算。
金鑰貼進 Pi Agent 之後會被上傳到 Woow 嗎？
不會。Pi Agent add-on 是開源的（MIT license），你可以自己去 GitHub 看程式碼，沒有一行會把 models.json（金鑰檔）上傳到外面。實際的資料流是「你的瀏覽器 → 你家 HA 主機的 pi-web → provider 官方端點（例如 open.bigmodel.cn）」，中間沒有 Woow 的伺服器。這也是 BYOK（Bring Your Own Key）的核心承諾：鑰匙留在你家硬碟。第 6 章「金鑰存哪」那節有更完整的說明。
已經填好 baseUrl 跟 api mode 但 Test 還是紅叉，怎麼確定是哪一格錯？
按 Pi Agent 右上 Models 面板卡片的 Edit，逐格對照這附錄的「Pi Agent 填法」表：（1）api mode 是不是選對（Anthropic 選 anthropic，其他選 openai-completions）；（2）baseUrl 是不是一字不差（含 https、含 /v1 或 /api/paas/v4、結尾沒有多 /）；（3）按金鑰欄位的眼睛圖示看內容，檢查頭尾沒空白、沒少字；（4）model 名字跟 provider 官方 docs 完全一樣（大小寫、連字號都要對）。四個都對還是不通，回頭看第 6 章的錯誤碼對照表——401 是金鑰錯、404 是地址錯、400 是 api mode 錯、402 是餘額不足。
Anthropic 為什麼特別要選 anthropic api mode？別人怎麼都用 openai-completions？
因為 Anthropic 的 API 協議自己一套，跟 OpenAI 那套不相容。它有兩個 openai-completions 表達不出來的功能：（1）native thinking blocks——Claude 會思考的模型（如 claude-opus-4-7）會把思考鏈用結構化欄位回傳，不是塞在文字裡；（2）cache_control——你可以標記 prompt 的某段自動快取，下次同樣前綴費用打 1 折。這些走 anthropic api mode 才能用；走 OpenRouter（強制 openai-completions）就會被拉平掉。所以重度用 Claude 的人建議直接跟 Anthropic 辦帳號、用 anthropic api mode，比走 OpenRouter 划算。第 12 章整章在解釋思考塊的價值，可以搭配看。
MiniMax 的國際版和中國版，我該選哪一個？
台灣使用者建議選國際版（api.minimax.io），原因：（1）台灣信用卡直接可以刷，不用搞支付寶；（2）介面是英文＋簡中，台灣人比較好讀；（3）從台灣連線延遲比較低。中國版（api.minimaxi.com，注意多一個 i）主要給中國境內用戶，付款要走支付寶／微信。切勿混用——同一支金鑰只在你註冊那邊可用，跨邊會 401；且模型定價兩邊可能不同。
